# Investigación del nicho

* `style_guide.json` — guía de estilo vigente (la leen el guionista y el banco de ideas).
* `report_<fecha>.md` — informes de cada investigación (`python -m fabrica research`).
* `videos_<fecha>.json` / `analysis_<fecha>.json` — datos crudos y análisis.

La guía actual es **inicial** (búsqueda web, sin cifras de la API). Para datos reales, configura una
clave de la YouTube Data API v3 y ejecuta la skill `investigar-nicho`.
